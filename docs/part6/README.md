# Part 6 · 产品化跃升——从能跑到能规模化

![Part 6 封面：多股力量汇聚成一枚发光的产品结晶](../../assets/images/part6-cover.png)

> Part 1~5 讲的是"怎么把一个 Agent 做出来、做扎实、做安全"。这个 Part 补上前面没有覆盖的四个维度——**怎么让它支持多模态、怎么验证它真的做得更好、怎么让它挣钱、怎么带团队把它做成**。这四件事，是一个 Agent 从"能跑的技术方案"跃升为"能规模化的产品"必须补的课。

本 Part 共4 章，读完你会获得：

- 一套多模态 Agent（语音/图片）的产品设计要点和分层架构思路
- 一套专门针对 Agent"非确定性输出+多步决策"设计的 AB 测试方法论
- 常见 Agent 定价模式的对比框架，以及怎么给自己的产品选定价模式
- 一套 Agent 项目的需求管理和跨团队协作方法，减少"需求模糊导致的反复拉锯"

| 章节 | 标题 | 一句话 |
|---|---|---|
| 21 | [多模态 Agent 专题](./21-多模态Agent专题.md) | 多模态的难点不是接入能看/能听的模型，是给感知层的不确定性设计兜底机制 |
| 22 | [Agent 产品的 AB 测试方法论](./22-Agent产品AB测试方法论.md) | 传统AB测试假设"同输入同输出"，Agent打破了这个前提，需要新方法论 |
